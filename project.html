PROJECT PROFILE · N1KMEL'S HUB

Характеристика проекта

N1kmeL's Hub — игровой веб-портал, который объединяет браузерные мини-игры разных жанров в одном пространстве. Главная задача проекта — сделать выбор и запуск игр простыми, быстрыми и удобными на компьютерах и мобильных устройствах.

Тип проекта

Интерактивный веб-портал с каталогом браузерных игр, авторскими игровыми страницами и дополнительными сервисными разделами.

Основная аудитория

Посетители, которым нравятся короткие игровые сессии, головоломки, аркады, творческие и учебные активности.

Технологии

HTML, CSS и JavaScript в интерфейсе; Node.js и Express для серверной части; Supabase для предусмотренных проектом данных и сервисов.

Организация

Каталог, отдельные игровые страницы, документация, пользовательское соглашение и адаптивное меню навигации.

Основные возможности

  • Каталог из 13 браузерных игр разных жанров.
  • Поиск по названию, фильтрация по жанру и ползунок быстрого перехода между карточками.
  • Адаптивная навигация с выдвижным меню, поддержкой клавиатуры и затемнением фона.
  • Mini Golf с пятью трассами и физикой движения мяча.
  • Пончик-Понг — аркадная игра против компьютерного соперника с выбором сложности.
  • Локальная статистика запусков и игровые рекорды в поддерживаемых играх.
  • Документация и пользовательское соглашение.

Принципы проекта

  • Доступность: интерфейс должен оставаться понятным на разных размерах экрана.
  • Удобство: карточки, поиск и навигация помогают быстро находить нужную игру.
  • Развитие: каталог и игровые механики могут обновляться и расширяться.
  • Ответственное использование: посетители соблюдают правила сайта и не пытаются нарушать его работу.
