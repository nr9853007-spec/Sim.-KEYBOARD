О проекте

𝑹𝒆𝒛1𝑵𝒂 𝑯𝒖𝒃 — портал с браузерными играми. Клиентская часть использует HTML, CSS и JavaScript; серверная часть построена на Node.js и Express, а данные аккаунтов, отзывов и обращений обрабатываются через Supabase.

Структура

  • index.html — главная и каталог игр.
  • hub.css, hub.js — стили, меню, каталог и локальная статистика.
  • server.js — сервер Express и API.
  • portal.js — интерфейс аккаунта, отзывов и поддержки.
  • supabase/schema.sql — SQL-схема.
  • neon-shards.html — головоломка «три в ряд».
  • docs.html — эта документация; terms.html — пользовательское соглашение.

Требования

  • Node.js 20 или новее.
  • Проект Supabase с применённой схемой supabase/schema.sql.
  • Переменные окружения: SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY, SUPABASE_SECRET_KEY.
  • Рекомендуется задать стабильный SESSION_SECRET. Порт задаётся через PORT (по умолчанию 3000).

Запуск

npm install
npm start

Открой http://localhost:3000. Без настроек Supabase серверные функции аккаунтов и поддержки не запустятся. Открытие index.html напрямую подходит только для статического просмотра.

API

В server.js определены маршруты здоровья сервера, регистрации, входа и выхода, профиля, отзывов, обращений, личных данных пользователя и административных операций. Полные методы и форматы запросов указаны в исходном файле.

Локальные игровые данные

Счётчик посещений каталога и рекорд Neon Shards хранятся в localStorage текущего браузера и не синхронизируются между устройствами.

Безопасность и эксплуатация

Не публикуй секретные ключи и пароли в репозитории. Для production настрой HTTPS, постоянное хранилище сессий, стабильный секрет сессии, резервное копирование и проверь политики доступа Supabase.
